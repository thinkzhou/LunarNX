# LunarNX 新手安装与使用指南

这份说明适合第一次使用 LunarNX 的用户。LunarNX 不会把 Xbox 或
PlayStation 游戏安装到 Switch：它负责把主机或 Xbox 云端的画面、声音和
手柄操作传到 Switch。

## 1. 使用前准备

- 一台能够运行 Homebrew NRO 的 Nintendo Switch。
- 建议使用稳定的 5 GHz Wi-Fi；条件允许时优先使用有线网络。
- Xbox 主机串流需要 Xbox One 或 Xbox Series 主机，并在主机上开启远程功能。
- Xbox 云游戏需要具有 Xbox Game Pass Ultimate（XGPU）云游戏权限的账号，
  同时受账号地区和服务可用性限制。
- PlayStation 串流需要 PS4 或 PS5，并在主机上开启远程游玩。
- 异地串流受双方网络、NAT、防火墙和运营商网络影响。LunarNX 不提供中继、
  VPN 或内网穿透服务，相关网络条件需要用户自行解决。

第一次使用时，建议先在同一局域网内完成登录、配对和串流测试；本地串流
正常后，再尝试异地串流。

## 2. 安装 LunarNX

1. 从 [GitHub Releases](https://github.com/thinkzhou/LunarNX/releases/latest)
   下载最新版本。
2. 用 USB、读卡器或你常用的 SD 卡管理工具将 Switch 连接到电脑。
3. 把完整的 `LunarNX` 文件夹复制到 SD 卡的 `switch` 目录。完成后的主要
   文件路径应为：

   ```text
   SD卡:/switch/LunarNX/LunarNX.nro
   ```

4. 安全弹出 SD 卡或结束 USB 文件传输，然后重启进入 Switch 自制系统。

不要只把压缩包放进 SD 卡，也不要多套一层目录。如果看到
`switch/LunarNX/LunarNX/LunarNX.nro`，说明目录层级多了一层。

## 3. 正确启动软件

串流需要完整内存模式，请不要直接从“相册”以 Applet Mode 启动。

可以使用以下任一方式：

- 从自制系统已有的前端进入 Homebrew Menu，再选择 **LunarNX**。
- 在 Switch HOME 菜单选中任意已安装的游戏，按住右侧 **R** 键并启动游戏；
  保持按住 R，直到 Homebrew Menu 出现，然后松开 R 并选择 **LunarNX**。

启动后先选择要使用的平台：**Xbox** 或 **PlayStation**。

## 4. Xbox 使用说明

### 4.1 登录 Microsoft 账号

1. 进入 **Xbox**，选择 **开始登录**。
2. 用手机或电脑扫描二维码，或者打开屏幕显示的网址。
3. 输入 LunarNX 显示的设备代码，并登录用于 Xbox 的 Microsoft 账号。
4. 授权完成后保持 LunarNX 打开，软件会自动进入 Xbox 首页。

登录信息只保存在 SD 卡上的 LunarNX 应用目录中。不要把该目录、Token 或
完整日志发给其他人。

### 4.2 Xbox 本地串流

主机端先完成以下设置：

1. 在 Xbox 的设置中开启**远程功能**。
2. 确认 Xbox 已登录刚才在 LunarNX 中使用的账号，并已联网。
3. 需要远程唤醒时，将主机电源选项设置为支持待机唤醒的模式。
4. 提前在 Xbox 主机上安装要玩的游戏；LunarNX 连接的是整台主机，不负责
   安装 Xbox 游戏。

然后在 LunarNX 中：

1. 打开左侧 **远程游玩**。
2. 选择 **查找我的 Xbox**。
3. 在“你的 Xbox 主机”中选择目标主机。
4. 主机在线时选择 **连接**；主机处于可唤醒状态时选择 **唤醒并连接**。
5. 连接后会进入 Xbox 主机画面，再从 Xbox 界面启动已安装的游戏。

### 4.3 Xbox 异地串流

Xbox 异地串流的操作入口与本地串流相同：登录账号、查找主机，然后连接。
区别在于 Switch 和 Xbox 不在同一局域网，连接需要两端网络能够建立兼容的
直连路径。

- 请先确认本地串流正常。
- Xbox 必须联网、开启远程功能，并保持开机或可远程唤醒状态。
- 严格 NAT、运营商 CGNAT、校园网/公司网限制或防火墙都可能导致失败。
- LunarNX 不负责配置路由器、端口、VPN 或内网穿透；异地网络需要用户自行
  调整和验证。

### 4.4 Xbox 云游戏

Xbox 云游戏不需要自己的 Xbox 主机，也不需要在 Switch 上安装游戏，但需要
具有云游戏权限的 **Xbox Game Pass Ultimate（XGPU）账号**。

1. 使用有 XGPU 权限的 Microsoft 账号登录。
2. 在左侧选择 **xCloud**。
3. 首次使用时加载或刷新游戏库；完整目录可能需要等待一段时间，成功后会
   使用本地缓存。
4. 使用 **ZL / ZR** 切换分类，按 **Y** 搜索，按 **X** 加载更多或刷新。
5. 选择游戏后按 **A**，再选择 **开始游戏**。

云游戏能否使用还取决于账号、地区、Microsoft 服务状态和当前网络。如果
提示 HTTP 403 或没有云游戏权限，请先检查登录账号与 XGPU 权限。

## 5. PlayStation 使用说明

### 5.1 主机准备与 PSN 登录

先在 PS4/PS5 上开启**远程游玩**。为了简化首次配对并方便以后尝试异地
串流，建议进入 LunarNX 的 **PlayStation** 页面后，先登录主机正在使用的
PlayStation Network（PSN）账号，再进行本地配对。

PSN 登录步骤：

1. 选择左下角的 **登录**。
2. 确保手机和 Switch 在同一局域网，然后用手机扫描二维码。
3. 在手机页面打开 Sony 登录页，登录用于远程游玩的 PSN 账号。
4. Sony 登录完成后可能停留在内容为 `redirect` 的空白页面。复制浏览器
   地址栏中的**完整地址**，包括 `code=` 后面的内容。
5. 返回手机上的 LunarNX 辅助页面，粘贴完整地址并发送给 Switch。
6. Switch 显示已登录后即可继续。

本地串流在协议上可以不登录 PSN，但首次使用仍推荐先登录；PSN 异地串流则
必须登录。

### 5.2 PS4 / PS5 本地串流

首次使用需要在同一局域网内完成配对：

1. 让 PlayStation 和 Switch 连接到同一个局域网。
2. 在 LunarNX 中打开 **局域网串流**，选择 **搜索局域网**。
3. 找到主机后选择 **配对**。如果搜索不到，可选择 **通过 IP 配对**，并
   正确选择 PS4 系统版本或 PS5。
4. 在 PlayStation 的远程游玩设置中选择“添加设备/关联设备”，取得当前
   显示的 8 位配对 PIN。
5. 按 LunarNX 页面提示输入账号信息和这组 8 位 PIN，完成配对。PIN 会过期，
   超时后请在主机上重新生成。
6. 配对成功后选择 **连接**；主机处于休眠且支持网络唤醒时，可选择
   **唤醒并连接**。
7. 进入 PlayStation 主机画面后，再从主机界面启动已经安装的游戏。

如果 PlayStation 用户设置了 4 位用户登录 PIN，建立串流时 LunarNX 还会
再次要求输入这组 4 位 PIN。它与首次配对用的 8 位 PIN 不是同一个密码。

### 5.3 PlayStation 异地串流

目前主要使用 **通过 PSN 远程** 连接账号中的 PS5：

1. 先确认 PS5 已开启远程游玩、已联网，并保持开机或可远程唤醒状态。
2. 建议先完成一次 PS5 本地串流测试。
3. 在 LunarNX 中完成 PSN 登录。
4. 打开 **通过 PSN 远程**，选择 **刷新 PSN**。
5. 在远程设备列表中选择已开启远程游玩的 PS5，然后选择 **连接**。
6. 等待 PSN 信令和网络打洞完成；部分网络第一次连接可能需要较长时间。

PSN 登录不等于网络一定可达。严格 NAT、防火墙、UDP 限制和运营商网络都
可能导致异地连接失败。LunarNX 不提供中继或网络穿透配置服务，相关网络
环境需要用户自行解决。

## 6. 串流中的菜单与退出

进入游戏画面后：

- 从触摸屏**右侧边缘向左滑动**，打开串流快捷菜单。
- 在快捷菜单中可以显示/隐藏性能信息、打开串流设置、修改当前平台的按键
  映射、发送 Xbox 键或 PS 键、继续串流，以及断开串流。
- 按 **B** 或在菜单显示时向右滑动，可关闭快捷菜单并返回游戏。
- 在菜单中选择 **断开串流** 后，需要再次选择确认，避免误触退出。
- 不方便触摸时，可在 3 秒内连续两次同时按下 **Minus + Plus**，安全断开
  当前串流。第一次会显示确认提示，第二次才会退出。
- 同时按 **L + R + Plus** 可直接发送 Xbox Guide/Nexus 键或 PlayStation
  PS 键。

串流设置和按键映射分为 Xbox、PlayStation 两套。串流中修改的画质设置通常
从下一次串流开始生效。

PlayStation 串流时，右缘菜单手势区域以外的触摸会作为远端触摸板输入；
轻点、长按和滑动会转发给 PS4/PS5。支持的 Switch 手柄还会转发体感数据，
远端震动或 DualSense 触觉反馈会转换为 Switch 手柄震动。

## 7. 默认按键

LunarNX 按按键的物理位置映射 Xbox 和 PlayStation 手柄：

| Switch | Xbox | PlayStation |
| --- | --- | --- |
| B（下） | A | × |
| A（右） | B | ○ |
| Y（左） | X | □ |
| X（上） | Y | △ |
| L / R | LB / RB | L1 / R1 |
| ZL / ZR | LT / RT | L2 / R2 |
| Minus | View | Share |
| Plus | Menu | Options |
| 左右摇杆按下 | L3 / R3 | L3 / R3 |
| L + R + Plus | Guide / Nexus | PS 键 |

Xbox 与 PlayStation 的按键可以分别在各自的设置页面中重新映射。
`Minus + Plus` 是 LunarNX 的安全退出组合，不能映射给远端主机。

## 8. 画质与网络建议

- 第一次连接或网络不稳定时，先选择 **720p**。
- 本地串流优先使用 5 GHz Wi-Fi，并让 Switch 靠近路由器。
- 1080p 和 1080p HQ 对网络稳定性要求更高；出现卡顿、马赛克或声音中断时，
  先降低画质再测试。
- Xbox 云游戏和异地串流同时受本地上/下行、主机端上行、延迟、抖动和丢包
  影响；带宽高不代表延迟和稳定性一定合格。

## 9. 常见问题

- **LunarNX 提示启动方式不正确：** 不要从相册直接启动。按住 R 打开完整
  内存模式的 Homebrew Menu，再启动 LunarNX。
- **Homebrew Menu 中找不到 LunarNX：** 检查文件是否位于
  `SD卡:/switch/LunarNX/LunarNX.nro`，并确认压缩包已经解压。
- **找不到 Xbox：** 检查 Microsoft 账号是否一致、Xbox 是否联网并开启远程
  功能，然后重新选择“查找我的 Xbox”。
- **Xbox 云游戏不可用：** 检查账号是否具有 XGPU 云游戏权限，以及账号地区
  是否支持该服务。
- **局域网找不到 PS4/PS5：** 确认两台设备在同一局域网、远程游玩已开启，
  并检查路由器是否启用了客户端隔离；也可以尝试通过 IP 配对。
- **PlayStation 配对失败：** 检查主机类型、PS4 系统版本、IP 地址和 8 位
  配对 PIN；过期后重新生成 PIN。
- **PSN 设备列表为空：** 确认登录的是主机使用的 PSN 账号、PS5 已启用远程
  游玩，然后重新刷新 PSN。
- **异地连接失败：** 先回到同一局域网验证账号、配对和串流功能。若本地正常
  而异地失败，通常需要自行排查 NAT、防火墙、运营商网络或 VPN/组网方案。
- **画面卡顿或马赛克：** 改用 720p、5 GHz Wi-Fi 或有线网络，并减少同一
  网络中的其他流量。

## 10. 隐私与反馈

`SD卡:/switch/LunarNX/` 中可能保存 Microsoft Token、PSN 会话、PlayStation
配对凭据、主机标识符和日志，请勿把整个目录公开上传。

反馈问题时请说明：Switch 型号和系统版本、LunarNX 版本、Xbox/PlayStation、
本地/异地/云游戏、所选画质、网络类型和错误现象。日志必须先脱敏，不要公开
Token、账号 ID、主机 ID、公网 IP 或未经处理的服务响应。
